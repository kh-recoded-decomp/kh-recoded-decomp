# Overlay 001 operational naming contracts

No matched C function in overlay 001 retains an address-based identifier. The names follow proved owners, callback slots, native operations and VM result protocols. This closes the identifier inventory, not every original gameplay meaning or portable type contract.

Native indices, masks and ranges remain visible where a stronger interpretation is unsupported. In particular, the original purpose of the no-op/run-zero commands, the payload feature, the resource family and session bit 5 are unknown. The persistent transition reaching menu phase 0 remains unproved even though its registered callback is now named. Erased native declarations are not certified host headers.
